# Project_A2
--ระบบจัดการข้อมูลสินค้าในคลัง (Inventory Management System)--
โปรแกรมจัดการข้อมูลสินค้าในคลัง พัฒนาด้วยภาษา Python โดยใช้ tkinter สำหรับสร้าง GUI โดยมีฟังก์ชันที่สามารถเพิ่ม แก้ไข ค้นหา ลบสินค้า และปรับจำนวนสินค้าในคลังได้ และบันทึกข้อมูลในไฟล์ txt เพื่อเก็บไว้เมื่อปิดโปรแกรม

--จุดประสงค์--
- เพื่อจัดการข้อมูลสินค้า ได้แก่ ชื่อสินค้า ราคา และจำนวนสินค้าในคลัง
- เพื่อให้ค้นหาและแก้ไขข้อมูลสินค้าได้สะดวก
- เพื่อเพิ่มหรือลดจำนวนสินค้าในคลังได้ตามต้องการ

--ฟังก์ชันของโปรแกรม--
- เพิ่มสินค้าใหม่ (เพิ่มชื่อสินค้า ราคา และจำนวนสินค้าเข้าสู่ระบบ)
- แก้ไขข้อมูลสินค้า (เปลี่ยนชื่อ ราคา หรือจำนวนของสินค้าที่เลือก)
- ค้นหาสินค้า (ค้นหาจากชื่อสินค้า โดยกรองข้อมูลขณะพิมพ์)
- เพิ่มจำนวนสต็อก (เพิ่มจำนวนสินค้าจากจำนวนที่ช้ระบุ)
- ลดจำนวนสต็อก (ลดจำนวนสินค้าจากจำนวนที่ระบุ)
- ลบสินค้า (ลบสินค้าที่เลือก)
- ล้างฟอร์ม (ล้างข้อมูลในช่องกรอก)
- บันทึกข้อมูล (บันทึกข้อมูลสินค้าในไฟล์)

--เครื่องมือและโมดูลที่ใช้--
- python (ภาษาที่ใช้ในการเขียนโปรแกรม)
- visual studio code (โปรแกรมที่ใช้ในการเขียนโค้ด)
- tkinter (ที่ใช้สร้างหน้าGUI)
- ttk (ใช้สร้างตารางแสดงข้อมูลสินค้าและแถบเลื่อน)
- messagebox (ใช้แสดงข้อความแจ้งเตือน ข้อผิดพลาด และการยืนยัน)
- simpledialog (ใช้รับจำนวนสินค้าที่ต้องการเพิ่มหรือลด)
- os (ใช้ตรวจสอบไฟล์ข้อมูล)

--การใช้งานฟังก์ชัน--
-เพิ่มสินค้า-
กรอกชื่อ ราคา และจำนวนสินค้า ในช่องจัดการข้อมูลสินค้า

-แก้ไขข้อมูลสินค้า-
เลือกสินค้าจากตาราง และเปลี่ยนข้อมูลตามที่ต้องการ

-ค้นหาสินค้า-
ใส่ชื่อค้าในแถบค้นหา

-เพิ่มหรือลดจำนวนสินค้า-
เมื่อกดปุ่มเพิ่มหรือลดสินค้า จะแสดงหน้าต่างให้กรอกจำนวนที่ต้องการและกดยืนยัน

-ลบสินค้า-
ลบสินค้าที่เลือกจากตาราง

-ล้างฟอร์ม-
ลบข้อความในช่องชื่อสินค้า ราคา และจำนวน โดยไม่ลบข้อมูลสินค้าออกจากคลัง

--ส่วนประกอบของโปรแกรม--
-OOP-
ใช้จัดกลุ่มข้อมูลและฟังก์ชันที่เกี่ยวข้องกับระบบจัดการคลังสินค้า

-list-
ใช้เก็บข้อมูลสินค้าแต่ละรายการ เช่น ชื่อสินค้า ราคา และจำนวนสินค้าในคลัง

-function-
ใช้แยกการทำงานออกเป็นส่วน ๆ เช่น เพิ่มสินค้า แก้ไขข้อมูล ลบสินค้า ค้นหาสินค้า และปรับจำนวนสินค้าในคลัง

-Conditional Statements-
ใช้ตรวจสอบเงื่อนไขต่าง ๆ เช่น ตรวจสอบว่าผู้ใช้กรอกข้อมูลครบหรือไม่ และตรวจสอบว่ามีสินค้าอยู่ในรายการที่เลือกหรือไม่

-Modules-
ใช้เรียกเครื่องมือจากไลบรารีต่าง ๆ เช่น tkinter สำหรับสร้างหน้าจอ, messagebox สำหรับแสดงข้อความแจ้งเตือน และ os สำหรับตรวจสอบหรือจัดการไฟล์
